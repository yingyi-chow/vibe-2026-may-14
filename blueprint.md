# Toto Number Generator

## Overview

A simple web application that allows users to generate random toto numbers.

## Project Outline

*   **`index.html`**: The main HTML file, now including the `<theme-toggle>` component.
*   **`style.css`**: The CSS file, refactored to use CSS variables for light and dark themes.
*   **`main.js`**: Contains the `LottoGenerator` and the new `ThemeToggle` web components.
*   **`blueprint.md`**: This file, which outlines the project.

## Current Plan

*   Create a web component for the lotto generator.
*   Add a button to trigger the number generation.
*   Display the generated numbers.
*   Style the application.
*   **Implemented**: Day/Night theme system with a `ThemeToggle` component and support for system preferences.
*   **Implemented**: UI/UX Overhaul:
    *   Auto-generation of numbers on page load.
    *   Staggered "pop-in" animations for numbers.
    *   Premium "lifted card" design with deep shadows and gradients.
    *   Subtle noise texture on the background for a tactile feel.
    *   Modern typography and gradient text for the main heading.
    *   Enhanced interactive button with hover/active states and a subtle glow.
